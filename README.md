# スカイライン・テクノロジーズ 企業サイト

架空のソフトウェア開発会社「スカイライン・テクノロジーズ株式会社」のコーポレートサイト（トップページ）です。

> ※ サイトに掲載している会社・人物・住所・実績はすべて架空のものです。

## 概要

HTML・CSS・JavaScript を 1 つのファイル（`index.html`）にまとめた静的サイトです。ビルドや依存パッケージのインストールは必要ありません。

### ページ構成

| セクション | 内容 |
| --- | --- |
| ヒーロー | キャッチコピーとお問い合わせへの導線 |
| 実績 | 主要な数値（カウントアップで表示） |
| 事業内容 | クラウドシステム開発／AI・データ活用／モバイルアプリ開発 |
| 会社紹介 | 企業理念・ビジョン |
| 導入事例 | これまでの開発事例 |
| 開発の流れ | ご相談からリリース・運用までのステップ |
| お知らせ | 最新ニュース |
| 会社概要 | 会社名、設立、所在地などの基本情報 |
| お問い合わせ | 連絡先と問い合わせフォーム |

### 主な機能

- レスポンシブ対応（スマートフォンではハンバーガーメニューで表示）
- スクロールに合わせて要素がふわっと表示されるアニメーション
- お知らせバーの自動切り替え
- 実績数値のカウントアップ表示
- 問い合わせフォームの入力チェック
- OS の「視差効果を減らす」設定が有効な場合はアニメーションを無効化

> 問い合わせフォームは画面上での入力チェックのみで、実際の送信は行いません。

## ブラウザで index.html を開く手順

### 方法 1：ファイルを直接開く（いちばん簡単）

1. ファイルマネージャー（エクスプローラー / Finder など）でこのフォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザでサイトが表示されます。

ブラウザのウィンドウに `index.html` をドラッグ＆ドロップしても開けます。

### 方法 2：コマンドで開く

このフォルダでターミナルを開き、お使いの OS に合わせて次のコマンドを実行します。

```bash
# Linux
xdg-open index.html

# macOS
open index.html

# Windows（PowerShell / コマンドプロンプト）
start index.html
```

### 方法 3：ローカルサーバーで開く（任意）

本番に近い状態で確認したい場合は、簡易 Web サーバーを起動して開きます。

```bash
# Python 3 がインストールされている場合
python3 -m http.server 8000
```

起動後、ブラウザで <http://localhost:8000/> を開きます。終了するときはターミナルで `Ctrl + C` を押します。
